# あっち向いてホイ・ゲーム（matching pennies 授業実習）

学生は「人間・柴犬・コンピュータ」のどれか1体と、40回のあっち向いてホイ（matching pennies）を行います。
学生が指さした方に相手が顔を向けたら学生に1点、違えば相手に1点です。

**相手はどの条件でも「左左右右」をくり返します。** 外見によって、この規則に気づく割合が変わるかを見ます。

## 実験の仕様

| 項目 | 内容 |
|---|---|
| 割り付け | 学籍番号＋`ASSIGN_SALT` のハッシュで3条件に分ける。リロードしても同じ条件になる |
| 相手の手 | `PATTERN`（初期値 LLRR）を1試行目から固定でくり返す |
| 相手の待ち時間 | 「あっち向いて…」から「ホイ！」まで 600〜1600ms の一様乱数。3条件で共通 |
| 毎試行の表示 | 相手の向き、勝ち負け、両者の得点 |
| 事後質問 | 「相手の出し方に何か規則はありましたか？」（自由記述・必須） |
| 端末 | スマホ・PC 両対応（PC はキーボードの ← → でも選べる） |

設定はすべて `config.js` で変えられます。

## 準備

### 1. ログを受け取るスプレッドシートを用意する

1. Google ドライブで新しいスプレッドシートを作る
2. **拡張機能 → Apps Script** を開く
3. `コード.gs` の中身を全部消して、`gas/Code.gs` の中身を貼り付ける
4. 先頭の `ADMIN_KEY` を好きな合言葉に変えて保存
5. **デプロイ → 新しいデプロイ** で、種類を「ウェブアプリ」にする
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 大学アカウントで「組織内の全員」しか選べない場合は、個人の Google アカウントで作ってください
6. 表示される **ウェブアプリ URL** をコピーする

記録は2つのタブに入ります。どちらも最初の記録が届いたときに自動で作られます。

- `trials`：1試行1行（1人40行）
- `participants`：1人1行（自由記述、前半・後半の勝率など）

同じ回の記録が二重に届いても、2回目は無視されます。

### 2. config.js に URL を貼る

```js
GAS_URL: 'https://script.google.com/macros/s/……/exec',
```

### 3. GitHub Pages で公開する

1. 新しいリポジトリを作る（例：`hoi-game`、Public）
2. このフォルダの中身をすべてアップロードする
3. **Settings → Pages** で Branch を **main / (root)** にして保存する

公開先は次のとおりです。

- 学生用：`https://<ユーザー名>.github.io/hoi-game/`
- 先生用：`https://<ユーザー名>.github.io/hoi-game/admin.html`

### 4. 動作確認

1. 学籍番号に **TEST** と入れて最後まで遊ぶ
2. スプレッドシートに `trials` 40行と `participants` 1行が入っていることを確認する
3. 先生用画面で URL と合言葉を入れて「読み込む」を押す
   - TEST で始まる学籍番号は、初期設定で集計から除外されます

確認用の URL もあります。

- `index.html?cond=shiba`：条件を指定して開く（記録の `cond_override` が 1 になる）
- `admin.html?demo=1`：ダミーデータでダッシュボードを見る

## 先生用画面（admin.html）

- 条件ごとの「気づいた」割合を表示します
  - 初期設定では、後半20試行の勝率が80%以上の人を「気づいた」と判定します
  - 基準は画面上で変えられます
- 4試行ごとの勝率の推移を条件別の折れ線で表示します
- 自由記述の一覧を表示します（見出しクリックで並べ替え）
- 投影モードでは、学籍番号を伏せて表示します
- CSV（参加者／全試行）を書き出せます。参加者の CSV は出欠確認にも使えます
- 同じ学籍番号が複数回遊んだ場合は、初期設定で最初の1回だけを集計します

## 注意

- 学生には、終了画面で「規則の答え合わせは授業で。まわりには話さないで」と表示されます。
- `SHOW_HISTORY: true` にすると、相手の過去の手が一覧で出ます。気づきやすくなり条件差が見えにくくなるので、初期値は `false` です。
